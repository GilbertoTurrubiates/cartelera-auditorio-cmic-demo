# Cartelera y Gestión del Auditorio CMIC - Prototipo Web Interactivo

Este repositorio contiene la versión de demostración web (*build/web*) del sistema de cartelera digital, reservación de asientos y gestión de accesos QR para el Auditorio **Alberto Aguilar Silva** de la CMIC Delegación Tamaulipas.

---

## 🚀 Probar la aplicación en vivo

Puedes interactuar con el prototipo navegando en el sitio publicado en **GitHub Pages**:

👉 **[Ver Demostración Web](https://GilbertoTurrubiates.github.io/cartelera-auditorio-cmic-demo/)**

---

## 📋 Módulos y Funcionalidades del Prototipo

* **Cartelera Pública de Eventos:** Filtro de eventos activos por categorías y búsqueda por nombre.
* **Mapa Interactivo del Auditorio:** Visualización de la distribución del recinto y selección/reserva dinámica de asientos por secciones.
* **Control de Acceso (Check-In QR):** Simulación de terminal de validación mediante escáner óptico o entrada manual de códigos.
* **Gestión de Instalaciones:** Galería promocional y módulo de información para renta del auditorio.
* **Exportación de Datos:** Descarga de reportes de asistencia y reservas.

---

## 🛠️ Tecnologías Utilizadas

* **Framework:** Flutter Web (Material Design 3)
* **Lenguaje:** Dart
* **Almacenamiento Local:** Persistence Web API / `SharedPreferences`
